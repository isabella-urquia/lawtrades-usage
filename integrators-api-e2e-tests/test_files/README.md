# Test Files Directory

This directory contains files used for testing file upload functionality in the E2E tests.

## Required Files

- `invoice-160.pdf`: Sample PDF file used for testing contract file uploads

## Adding Test Files

1. Place any new test files in this directory
2. Update this README to document the new files
3. Make sure to use appropriate sample files (not containing sensitive information)
4. Keep test files small in size

## File Types

Currently supported file types for testing:
- PDF files (.pdf)
